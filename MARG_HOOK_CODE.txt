myv_bill=trim(invo)

  myv_flds="PHONE4,PHONE3,PHONE2,PHONE1"

STEP 2 — HEADER END   (optional safety net)
================================================================================
Only needed if Marg ever moves the ORDER pointer before FOOTER runs. It grabs
the mobile earlier and parks it in a PUBLIC variable the FOOTER checks first.

PUBLIC marg_wa_phone
marg_wa_phone=""
IF USED("ORDER")
  myv_flds="PHONE4,PHONE3,PHONE2,PHONE1"
  FOR ln_p=1 TO GETWORDCOUNT(myv_flds,",")
    myv_try=CHRTRAN(ALLTRIM(TRANSFORM(EVALUATE("ORDER."+GETWORDNUM(myv_flds,ln_p,",")))),"+- ()./,","")
    IF LEN(myv_try)>=10
      myv_try=RIGHT(myv_try,10)
      IF LEFT(myv_try,1)$"6789"
        marg_wa_phone=myv_try
        EXIT
      ENDIF
    ENDIF
  ENDFOR
ENDIF
=strtofile(marg_wa_phone,"D:/MARGERP/HOOK_DATA/phone.txt")
retu .t.

If HOOK_DATA\phone.txt never appears after saving a bill, this hook is not
installed — which is fine, STEP 1 covers it on its own.

================================================================================
CONFIRMED FIELD MAP (this installation)
================================================================================
Bill no       INVO             e.g. VMA0453
Party code    PCOD             e.g. WAD     <- bill alias code
Party name    CHEMI_NAME       party name as printed on the bill
G Total       FINALBILVAL
Date          REPDAT1
Party master  alias ORDER      D:/MARGERP/DATA/ORDER.A20, ~1900 records
  SCODE       internal code    e.g. C6      <- NOT the same as PCOD
  PARNAM      party name, space-padded ("NAME     CITY")
  PHONE4      10-digit mobile               <- PHONE1..3 empty in our data

Because PCOD (WAD) != SCODE (C6) and PARNAM is padded, LOCATE on either one
fails. That is why the hooks read ORDER's CURRENT record instead of searching.

Never use: invopho (always blank here), order.mobile / order.mob (no such
field), MEMOREAD() (missing from Marg's runtime - use FILETOSTR), sndlast_5
(does not exist at FOOTER), vou_position, an.

================================================================================
CONFIG (config/config.json)
================================================================================
  "send_mode": "yes_only"    send only when you answer Y   (default)
  "send_mode": "always"      send on every save - then delete the popup block
  "pdf_wait_seconds": 10     how long to wait for Marg's PDF
  "pdf_search_folders": ["D:/MARGERP/EXPORT/BILLS/"]

Bill PDF: if Marg has not written EXPORT/BILLS/<bill>.pdf within the wait,
Python generates a summary invoice PDF and sends that instead.

Troubleshooting
  Mobile shows NOT FOUND    -> party has no number in ledger master, or it sits
                               in a field other than PHONE1..PHONE4
  "WhatsApp server offline" -> START_SERVER.bat is not running
  "<NAME>.PRG does not exist" -> that function is missing from Marg's runtime;
                               FoxPro treats unknown names as program calls
